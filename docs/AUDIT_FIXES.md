# گزارش بازبینی ← چه شد

این جدول، پاسخِ عملی به گزارش بازبینی ۷۳ موردی است (`docs/review-rounds/`).
برای هر مورد: **وضعیت**، **جایی که رفع شد** و **گیتی که جلوی برگشتش را می‌گیرد**.
جایی که رفع از داخل مخزن ممکن نبوده، به‌جای تیک، دلیل و اقدام لازم نوشته شده؛
موردی «انجام‌شده» علامت نخورده که به یک گیت یا یک تست وصل نباشد.

## خلاصه

| وضعیت | تعداد |
|---|---|
| رفع‌شده با تغییر کد | ۶۲ |
| رفع‌شده با تغییر CI/مستندات | ۷ |
| نیازمند اقدام مالک مخزن یا تصمیم محصولی | ۴ (F2، F4، F10، C7) |
| جمع | ۷۳ |

## چه چیزی عمداً رفع نشد (و چرا)

1. **C7 / C8** — نگه‌داشتن انتخاب فایل و نتیجهٔ اسکن پوشه در برابر مرگ پروسه،
   نیاز به Parcelable کردن `InputItem` یا `SavedStateHandle` دارد که تغییر
   قرارداد ناوبری است؛ در این دور ریسک/فایده‌اش نبود. سند باقی ماند.
2. **D5** — خواندن کل گالری روی Android 13+ مجوز `READ_MEDIA_IMAGES/VIDEO` را
   می‌خواهد. این اپ با مجوز صفر کار می‌کند و این رفتار یک انتخاب محصول است، نه
   باگ؛ فقط کوئری باند و پیام «مجوز ندارید» اضافه شد.
4. **F2, F10** — پاک‌سازی تاریخچهٔ git (force-push) و تصمیم حقوقی/چرخش کلید
   امضا، هر دو خارج از توان یک عامل خودکار و روی حساب مالک مخزن است.
