# نقشه راه تعمیرات — دور ۱۵ (۳۱ اوت ۲۰۲۶)

وضعیت: ✅ انجام شد (نسخه ۱.۰.۱)

این دور گزارش‌های قبلی را تکرار نمی‌کند. کد فعلی دوباره خوانده شد و نقص‌هایی که هنوز در سورس بودند فهرست شدند.

## فاز ۱ — باگ‌های بحرانی (صدا / پایداری)

| شناسه | مشکل | تعمیر |
|---|---|---|
| **CRASH-UI** | دیالوگ بازیابی کرش با `remember { consumeCrash() }` ساخته می‌شود و `onDismiss` خالی است؛ دیالوگ هرگز بسته نمی‌شود. | state قابل‌تغییر |
| **AAC-FLOAT** | مسیر AAC همیشه PCM را ۱۶بیتی می‌خواند. FLAC/WAV روی دستگاه‌های جدید `PCM_FLOAT` می‌دهد → صدای خراب. | تبدیل float→۱۶بیت قبل از downmix |
| **AAC-DROP** | فریم PCM بزرگ‌تر از ۶۴KB فقط تا ظرفیت بافر کپی می‌شد و بقیه دور ریخته می‌شد. | بزرگ‌کردن بافر به‌اندازهٔ واقعی |
| **MONO-R** | مونو→استریو کانال راست را صفر می‌گذاشت (سکوت در یک گوشی). | تکرار کانال چپ |
| **MUX-FLAGS** | در merge، `sampleFlags` صدا **بعد از** `advance()` خوانده می‌شد (فلگ نمونهٔ بعدی). | خواندن فلگ قبل از advance |
| **IAP-CONNECT** | `PoolakeyBillingManager.connect()` هیچ‌جا صدا زده نمی‌شد؛ خرید همیشه no-op بود. | connect در صفحهٔ پریمیوم |
| **URI-GRANT** | URIهای SAF persistable نمی‌شدند؛ کار پس‌زمینه ممکن بود `SecurityException` بدهد. | `takePersistableUriPermission` |

## فاز ۲ — باگ‌های مهم (UX / فایل)

| شناسه | مشکل | تعمیر |
|---|---|---|
| **THEME-BLOBS** | پس‌زمینهٔ صفحهٔ اصلی `isSystemInDarkTheme()` است، نه تم کاربر. | از luminance تم فعلی |
| **DBL-CLICK** | کارت ماژول هم `PressableCard` هم `clickable` داخلی داشت → دابل‌فایِر. | یک کلیک |
| **PHOTO-TEMP** | نام فایل موقت عکس با میلی‌ثانیه؛ برخورد در بچ. | `nanoTime` |
| **ADS-PREM** | `AdSlot` پریمیوم را چک نمی‌کرد (پیش‌فرض false). | خواندن DataStore |
| **PLAY-PREM** | بنر خرید بازار در بیلد پلی (بدون IAP) نمایش داده می‌شد. | فقط flavor بازار |
| **META-SMART** | تغییر سوئیچ متادیتا حالت هوشمند را خاموش می‌کرد. | بدون disableSmart |
| **DOT-SIZE** | نقطه‌های آنبوردینگ عرض را درست انیمیت نمی‌کردند. | width انیمیت‌شده |
| **EN-STR** | `pick_error_too_large` در انگلیسی نبود. | اضافه شد |
