# docs/ — نقشهٔ فایل‌ها (F7)

این پوشه چند دورهٔ مستندسازی دارد و بعضی فایل‌ها هم‌پوشانی زیادی دارند. برای
اینکه معلوم باشد کدام سند «وضعیت فعلی» است و کدام تاریخ است، این فهرست را مبنا
بگیرید.

## اسناد زنده (منبع حقیقت)

| فایل | چه چیزی را می‌گوید |
|---|---|
| `KNOWN_ISSUES.md` | کارهای باز، با دامنهٔ دقیق هر مورد. **قبل از هر انتشار بخوانید.** |
| `THIRD_PARTY_NOTICES.md` | تعهدات پروانهٔ کتابخانه‌ها (LGPL) + استعلام باز GPL. |
| `AUDIT_FIXES.md` | نتیجهٔ بازبینی جامع کد (۷۳ مورد) و اینکه هر مورد رفع شد یا نه. |
| `COMPRESSLY_CAPABILITIES.md` | فهرست قابلیت‌ها به‌تفکیک نوع رسانه. |
| `SETTINGS_CONSUMERS.md` | هر تنظیم کاربر کدام مصرف‌کنندهٔ واقعی در کد دارد. |
| `BENCHMARK.md` | روش اندازه‌گیری عملکرد/حجم (خالی تا وقتی اندازه‌گیری واقعی انجام شود). |

## اسناد تاریخی (نگه داشته شده، به‌روز نمی‌شود)

این فایل‌ها برنامه‌های دوره‌ای قبلی‌اند و بخش زیادی از محتوایشان اکنون در کد
پیاده شده یا در `KNOWN_ISSUES.md` و `AUDIT_FIXES.md` جمع شده است. حذف نشده‌اند
چون سابقهٔ تصمیم‌ها را نگه می‌دارند:

- `ROADMAP.md`
- `ROADMAP_FIXES.md`
- `MASTER_ROADMAP.md`
- `SCORE_ROADMAP.md`
- `UPGRADE_ROADMAP.md`
- `COMPRESSLY_SCORECARD.md`
- `review-rounds/` (گزارش دورهای بازبینی قبلی)

اگر چیزی از این‌ها هنوز باز است، در `KNOWN_ISSUES.md` ثبت شده — نه در خودشان.
