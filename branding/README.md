# برند «حجمنو» / Compressly — منابع بازاریابی

این پوشه منابع برند و بازاریابی را نگه می‌دارد تا صفحهٔ بازار (Café Bazaar) و سایت لندینگ
از یک هویت یکپارچه استفاده کنند. رنگ‌ها و گلیف مستقیماً از خودِ برنامه استخراج شده‌اند.

## هویت بصری (از منابع برنامه)
- **آیکون:** مربع گرد با گرادیان `#5B21C9 → #8B5CF6` و گلیف سفید «قیف فشرده‌سازی»
  (دو ذوزنقهٔ روی‌هم + یک رعد در پایین) — منبع: `app/src/main/res/mipmap-*/ic_launcher.png`.
- **پس‌زمینهٔ تیره:** `#12131B` (splash) و `#0E0F16` (window dark).
- **پس‌زمینهٔ روشن:** `#F7F7FB`.
- **لهجه:** بنفش-نیلی، شعاع گرادیان ملایم.

## متن کوتاه صفحهٔ بازار (فارسی)
> **حجمنو** — فشرده‌ساز قوی، آفلاین و رایگان عکس، ویدیو و صدا. حجم فایل‌ها را بدون
> افت محسوس کم کنید؛ تا 4K و ۶۰ فریم، با کدک H.264 / H.265 / AV1، تریم، هدف‌حجم و
> پشتیبانی HDR. **بدون اینترنت، بدون آپلود، بدون ردیابی — همه‌چیز روی خودِ گوشی.**
> اگر بازکدینگ فایل را کوچک‌تر نکرد، خودِ فایل اصلی برگردانده می‌شود.

## متن کوتاه صفحهٔ بازار (English)
> **Compressly** — a powerful, offline, free image / video / audio compressor. Shrink
> files with no visible quality loss: up to 4K60, H.264 / H.265 / AV1, trim, target
> size and HDR pass-through. **No internet, no uploads, no tracking — everything stays
> on your device.** If re-encoding wouldn't help, the original is returned honestly.
